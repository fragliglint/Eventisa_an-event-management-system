# Eventisa – Event Booking & Management Platform

Eventisa is a modern, responsive web application built to streamline the event booking experience. It features elegant UI, smooth booking flows, modular PHP structure, and support for scalable feature integration. Designed with performance and ease of use in mind, this project is perfect for showcasing on a professional portfolio or deploying as a practical booking platform.

---

## ✅ Highlights

- 🎨 Modern and Responsive UI  
- 📅 Event Listing & Detail Pages  
- 🛒 Seamless Booking Process  
- ⚡ Fast Load and Clean Structure  
- 🧩 API & Backend Integration Ready  
- 📁 Organized Folder Architecture  
- 📱 Mobile and Desktop Friendly  

---

## 🏗️ Project Overview

Eventisa enables users to explore events and complete bookings through a guided multi-step process. It combines a polished frontend with a functional backend structure (PHP + optional MySQL), making customization and deployment straightforward.

Use cases include:
- Conferences  
- Concerts  
- Festivals  
- Corporate Events  
- Workshops  
- Social Gatherings

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/fragliglint/Eventisa_an-event-management-system
```

### 2. Navigate into the Project
```bash
cd Eventisa_an-event-management-system
```

### 3. Local Server Setup

Move the folder into:
- `htdocs` (XAMPP), or
- `www` (WAMP/Laragon)

Access it via:
```
http://localhost/eventisa/Eventisa_an-event-management-system
```

### 4. Database Configuration (If Required)
- Import the SQL file using phpMyAdmin
- Update credentials in any config file (e.g., `config.php`)

---

## ▶️ How to Use

1. Open the home page (`index.php`)
2. Browse available events
3. Click an event for details
4. Proceed to booking via `booking-process.php`
5. Submit details and confirm

You can customize the booking flow, fields, and event data as needed.
